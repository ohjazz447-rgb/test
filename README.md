# Royal Park Rajapruek — Cinematic Scroll v3

ปรับจากเวอร์ชัน v2 โดย **ข้อความทุกส่วนเลื่อนตามการ scroll ของหน้าเว็บ** ไม่ติดค้างอยู่กับภาพ:

- ภาพ WebP 92 เฟรมยังเป็นฉากหลังแบบ sticky และเปลี่ยนตามระดับการ scroll
- ข้อความหัวเว็บ ชื่อเรื่อง คำบรรยายทุกฉาก และปุ่มต่าง ๆ อยู่บนชั้นเนื้อหาที่เลื่อนขึ้นไปตามหน้าเว็บจริง
- มี 3 ช่วง: ภายในหอคำหลวง → ผ่านประตู → เผยหอคำหลวงภายนอก
- แถบความคืบหน้าเป็นกราฟิกเส้นบางไม่ใช่ข้อความ จึงยังอยู่ในฉากภาพเพื่อช่วยระบุตำแหน่ง
- ขณะเล่นอัตโนมัติ จะมีปุ่มไอคอนหยุดชั่วคราวบริเวณด้านขวาล่างเพื่อให้กดหยุดได้ตลอดทาง
- ปุ่มเริ่มใหม่อยู่ในข้อความของฉากสุดท้าย (เลื่อนตามหน้าเว็บ)
- รองรับ responsive และ `prefers-reduced-motion`

## ทดลอง

แตก ZIP แล้วเปิด `index.html` ใน Chrome, Edge หรือ Firefox; ไม่ต้องติดตั้งแพ็กเกจและไม่ต้องมีอินเทอร์เน็ต

## หมายเหตุ

ภาพและสถาปัตยกรรมทั้งหมดเป็นภาพจำลองเพื่อทดสอบงาน ไม่ใช่ภาพถ่าย/โมเดล 3D ของหอคำหลวงจริง
